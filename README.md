# ECA0801 - Analog and Digital Communication 

This repository contains MATLAB simulations for three experiments related to Analog and Digital Communication (ADC).

## Experiments

### 1. Characteristics Study of Sideband Power and Frequencies in AM Using MATLAB
- Generates the message signal, carrier signal, AM-modulated signal, and demodulated signal.
- Displays the AM frequency spectrum and compares carrier, upper-sideband (USB), and lower-sideband (LSB) power.
- Demonstrates modulation index, sideband frequencies, and AM power distribution.

### 2. MATLAB Simulation of VSB Modulator and Demodulator for Analog Television Communication Applications
- Generates message and carrier signals.
- Models DSB-SC modulation followed by filtering to obtain the simulated VSB signal.
- Performs coherent demodulation and low-pass filtering to recover the message.
- Plots the message, carrier, DSB-SC, VSB, and recovered signals.

### 3. MATLAB Simulation of Superheterodyne Receiver for AM Communication System with Frequency Mixing and Filtering
- Generates the message, carrier, and AM signals.
- Mixes the AM signal with a local-oscillator signal to produce frequency components.
- Applies intermediate-frequency (IF) filtering.
- Uses envelope detection to display the recovered signal.

## Requirements
- MATLAB or MATLAB Online.
- Signal Processing Toolbox functions used by the scripts include `butter` and `hilbert`.

## How to Run
1. Open MATLAB or MATLAB Online.
2. Open the `.m` script for the experiment you want to run.
3. Run the script.
4. View the generated plots and any values displayed in the Command Window.
